5학년 2학기 창체 평어 활용 팁

학생 선택부터 내 평어함까지 단계별 사용법과 실제 활용 요령을 확인할 수 있습니다.

같은 키워드라도 문장이 똑같이 반복되지 않도록 구성했습니다.

동일한 키워드와 수준을 선택하더라도 학생별 평어가 가능한 한 서로 다른 문장으로 생성되도록 문장 구조·서술 순서·표현을 다양화하는 방식을 적용했습니다. 다만 AI 생성 결과가 항상 완벽하다고 보장할 수는 없으므로, 최종 사용 전에는 모든 문장을 한 번씩 읽어 사실관계·표현·중복 여부에 문제가 없는지 확인해 주세요.

학생 선택

5학년 창체에서는 같은 활동에 참여해도 맡은 역할, 협력 방식, 주도성, 성찰 모습이 학생마다 다르게 나타날 수 있습니다.

기능 설명

한 학생 모드와 여러 학생 일괄 모드를 지원합니다. 여러 학생을 선택하면 ‘학생별 추가 기술’을 펼쳐 같은 활동 안에서 학생마다 다른 참여 모습을 따로 입력할 수 있습니다.

활용 요령

학급회의·동아리·진로활동처럼 공통 활동 맥락은 교사 자유 기술에 적고, 학생별 역할이나 참여 차이는 학생별 추가 기술에 구분해 기록하세요.

실제 예시

예: 동아리 ‘코딩·소프트웨어’ 활동 학생들을 일괄 선택하고, 학생별로 블록코딩 참여, 역할 수행, 친구와의 협력 모습을 추가 기술에 다르게 적습니다.

주의사항

같은 동아리나 행사에 참여했다는 이유만으로 모든 학생에게 동일한 역할·성과를 적지 마세요. 실제 참여와 관찰이 학생별로 구분되어야 합니다.

키워드 선택

창체 키워드는 자율·자치, 동아리, 진로의 실제 활동 참여를 중심으로 선택합니다.

기능 설명

영역은 자율·자치활동, 동아리활동, 진로활동으로 나뉩니다. 상위 활동 키워드를 선택하면 해당 활동에만 연결된 하위 키워드가 펼쳐집니다. 좌클릭은 매우 잘함 → 잘함 → 보통 → 해제 순입니다.

활용 요령

상위 키워드는 활동의 큰 초점을 잡는 데 쓰고, 하위 키워드는 그 활동에서 실제로 관찰한 역할·협력·과정 등을 좁혀 적는 데 사용하세요. 우클릭하면 즉시 해제되며 상위 우클릭 시 연결된 하위 선택도 함께 해제됩니다.

실제 예시

예: 동아리활동 → 코딩·소프트웨어에서 ‘블록코딩’을 선택한 뒤, 활동 과정에서 실제로 확인한 세부 참여 근거를 하위 키워드와 실제 활동명으로 보완할 수 있습니다.

주의사항

여기서 ‘매우 잘함·잘함·보통’은 공식 교과 성취수준을 대신하는 표현이 아니라 활동 특기사항을 만들기 위한 선택 정보입니다. 참여하지 않은 활동이나 맡지 않은 역할을 선택하지 마세요.

문장 수

창체 특기사항은 활동 하나의 특징만 간단히 기록할지, 참여·역할·성찰을 나누어 기록할지에 따라 문장 수를 정합니다.

기능 설명

학생당 1~5문장을 설정할 수 있습니다. 핵심 참여 모습 하나면 1문장, 역할 수행과 협력 또는 활동 결과와 성찰처럼 서로 다른 근거가 있으면 2~3문장이 적합합니다.

활용 요령

선택한 키워드가 많더라도 모두 문장에 넣을 필요는 없습니다. 비슷한 내용은 묶고 성격이 다른 활동 근거만 문장을 나누세요.

실제 예시

예: 학급회의에서 의견을 제안한 모습과 친구 의견을 반영해 조정한 모습이 모두 관찰되었다면, 한 문장에 길게 나열하기보다 참여와 조정 과정을 2문장으로 나눌 수 있습니다.

주의사항

문장 수에 맞추려고 활동하지 않은 내용이나 결과를 추가하지 마세요. 근거가 적다면 짧은 문장이 더 정확합니다.

AI 평어 생성

5학년 창체에서는 단순 참여 여부보다 역할 수행, 협력, 주도성, 진로 탐색 과정과 활동 후 성찰이 실제로 어떻게 나타났는지 확인하는 것이 중요합니다.

문장 다양화 기능

같은 키워드를 여러 학생에게 사용해도 가능한 한 같은 문장을 그대로 반복하지 않도록 생성 과정에서 표현과 문장 구조를 달리하도록 구성되어 있습니다. 그래도 학생별 실제 관찰 근거가 다르면 학생별 추가 기술에 그 차이를 적어 주는 것이 가장 효과적입니다.

기능 설명

교사 자유 기술, 일괄 모드의 학생별 추가 기술, 각 활동 영역의 실제 활동명, 선택 키워드와 수준, 참고 문서의 파일명·문서별 참고 지침을 바탕으로 Gemini API가 특기사항 초안을 생성합니다.

활용 요령

‘학급회의에서 친구 의견을 듣고 자신의 제안을 수정함’, ‘코딩 동아리에서 오류 원인을 찾고 해결 방법을 친구와 비교함’처럼 실제 활동 장면을 짧게 적으세요.

실제 예시

예: 동아리의 실제 활동명에 ‘마이크로비트 센서 프로젝트’를 적고, 학생별 추가 기술에 맡은 역할과 협력 모습을 기록한 뒤 관련 키워드로 초안을 생성할 수 있습니다.

주의사항

교사의 실제 관찰 기록이 최우선이며 AI 결과는 초안입니다. 현재 직접 API 호출은 첨부 파일 본문을 자동 전송하지 않고 파일명과 문서별 참고 지침을 반영합니다. 실제 문서 내용은 핵심을 참고 지침 또는 자유 기술에 직접 적고, 참여하지 않은 활동·확인되지 않은 성과·학생의 마음이나 의도를 추정한 문장이 없는지 확인하세요.

내 평어함

생성된 특기사항은 내 평어함으로 옮겨 학생별로 다듬고 저장한 뒤 최종 기록에 활용합니다.

마지막으로 한 번 읽어보기

자동 문장 다양화와 중복 확인 기능이 적용되어 있어도 최종 판단은 교사의 몫입니다. 내 평어함으로 옮긴 뒤 학생별 문장을 한 번씩 읽어 실제 관찰 내용과 맞는지, 지나치게 비슷한 문장이나 어색한 표현은 없는지 확인한 후 사용해 주세요.

기능 설명

학생별 생성 결과를 기존 평어함 지우고 붙이기 또는 평어함 뒤에 이어붙이기로 옮길 수 있습니다. 내 평어함에서는 직접 수정, 문장별 AI 재생성, 전체 재작성, 글자 수·문장 수 줄이기와 저장 기능을 제공합니다.

활용 요령

활동명·역할·협력 모습이 실제 관찰과 맞는지 확인한 뒤 수정 저장하세요. 영역별/전체 Excel 내보내기와 JSON 백업·복원 기능을 함께 이용할 수 있습니다.

실제 예시

예: 동아리 생성 결과를 평어함에 추가 → 학생별 역할 표현 수정 → 동일 문장 검사 → 전체 수정 저장 → 자율·자치·동아리·진로 전체 Excel 저장 순으로 정리합니다.

주의사항

‘같은 문장 검사·다르게 만들기’는 완전히 같은 문장만 확인합니다. 서로 다른 문장을 의미가 비슷하다는 이유로 자동으로 모두 바꾸지는 않습니다. Excel 복원은 평어 본문 중심이고 JSON 백업은 작업 상태를 더 폭넓게 보관합니다.

자동 다양화와 중복 확인을 활용하되, 최종 사용 전 학생별 문장을 한 번 확인해 주세요.
