기본 흐름에 따라 필요한 단계만 선택해 확인하세요. 실제 학생의 관찰·평가 기록이 항상 가장 우선입니다.

같은 키워드라도 문장이 똑같이 반복되지 않도록 구성했습니다.

동일한 키워드와 수준을 선택하더라도 학생별 평어가 가능한 한 서로 다른 문장으로 생성되도록 문장 구조·서술 순서·표현을 다양화하는 방식을 적용했습니다. 다만 AI 생성 결과가 항상 완벽하다고 보장할 수는 없으므로, 최종 사용 전에는 모든 문장을 한 번씩 읽어 사실관계·표현·중복 여부에 문제가 없는지 확인해 주세요.

1. 학생 선택

창체 특기사항을 작성할 학생을 선택합니다. 6학년은 자율·자치, 동아리, 진로 활동에서 주도성과 협력 과정이 드러나는 실제 장면을 구분해 두는 것이 좋습니다.

한 학생

개별 역할과 성장 과정을 자세히 기록할 때 적합합니다.

여러 학생 일괄

같은 활동에 참여한 여러 학생의 초안을 만들 때 적합합니다.

활용 요령

같은 활동을 했더라도 학생별 역할·기여·변화가 다르므로 학생별 추가 기술을 활용하세요.

예시

“축제 준비에서 일정 정리를 맡아 친구 의견을 조정함”, “진로 조사에서 관심 직업의 필요한 역량을 찾아봄”처럼 적습니다.

주의

같은 동아리라는 이유만으로 모든 학생에게 같은 역할과 성과를 부여하지 마세요.

2. 키워드 선택

창체 영역과 실제 활동에 맞는 상위 키워드를 고르고, 필요한 경우 해당 활동 전용 하위 키워드를 선택합니다.

상위 활동

참여한 활동의 핵심 성격을 선택합니다.

하위 키워드

그 활동에서 드러난 협력, 주도성, 성찰, 진로 탐색 등의 구체적 모습을 추가합니다.

활용 요령

6학년은 “참여함”만 기록하기보다 스스로 계획함, 역할을 조정함, 결과를 성찰함 같은 고학년 활동 과정을 선택하면 좋습니다.

예시

상위 “학급 자치 활동” + 하위 “의견 조정”, “역할 책임”, “활동 결과 성찰”처럼 실제 장면과 연결합니다.

주의

활동에 참여하지 않았거나 관찰하지 않은 하위 키워드는 선택하지 마세요.

3. 문장 수

활동 수와 학생의 역할·성장 근거에 맞게 문장 수를 정합니다.

1문장

한 활동의 핵심 특기사항을 간결하게 기록할 때 사용합니다.

2~3문장

활동 과정과 성장·성찰을 나누어 기록할 때 사용합니다.

활용 요령

여러 활동을 한 문장에 모두 넣기보다 중요한 활동을 선별하거나 문장을 나누는 편이 읽기 쉽습니다.

예시

동아리 활동 1문장 + 진로 탐색 1문장처럼 성격이 다른 활동은 분리할 수 있습니다.

주의

활동명만 나열하고 학생의 역할이나 변화가 없는 문장이 되지 않도록 주의하세요.

4. AI 평어 생성

활동 키워드와 교사가 입력한 실제 참여 모습, 학생별 기록, 참고 문서를 근거로 특기사항 초안을 생성합니다.

문장 다양화 기능

같은 키워드를 여러 학생에게 사용해도 가능한 한 같은 문장을 그대로 반복하지 않도록 생성 과정에서 표현과 문장 구조를 달리하도록 구성되어 있습니다. 그래도 학생별 실제 관찰 근거가 다르면 학생별 추가 기술에 그 차이를 적어 주는 것이 가장 효과적입니다.

실제 활동명

학교에서 사용한 프로그램·프로젝트명을 입력하면 맥락이 더 정확해집니다.

교사 관찰

역할, 협력, 주도성, 변화 등 확인 가능한 내용을 우선 입력합니다.

활용 요령

6학년은 진로 탐색과 공동체 활동에서 학생이 스스로 선택·계획·조정한 과정이 있으면 구체적으로 반영하세요.

예시

“영상 제작에서 편집 역할을 맡고 팀원의 피드백을 반영해 수정함”처럼 과정이 드러나는 기록이 좋습니다.

주의

AI가 활동 성과를 과장하거나 실제로 하지 않은 발표·제작을 만들어내지 않았는지 확인하세요.

5. 내 평어함

생성된 특기사항을 학생별로 옮긴 뒤 수정·정리하고 최종 자료로 저장합니다.

학생별 수정

활동명, 역할, 표현을 실제 기록에 맞게 바로잡습니다.

백업/내보내기

검토가 끝난 자료는 Excel 또는 JSON으로 저장합니다.

활용 요령

같은 활동에 참여한 학생끼리 문장이 지나치게 비슷하지 않은지 확인하고 실제 역할 차이를 반영하세요.

예시

A학생은 기획, B학생은 발표, C학생은 자료 조사처럼 관찰된 역할을 기준으로 문장을 다르게 정리합니다.

주의

생성 문장을 그대로 확정하지 말고 실제 창체 누가기록과 일치하는지 최종 확인하세요.

내 평어함 이동 확인

평어를 옮기면 저장 완료 팝업에서 실제로 저장된 최종 내용을 바로 확인할 수 있습니다. ‘기존 평어함 지우고 붙이기’는 기존 내용이 있을 경우 먼저 기존 평어와 새 평어를 함께 보여 주며, 교체 여부를 확인한 뒤 실행됩니다.
