5학년 2학기 행동특성 및 종합의견 활용 팁

학생 선택부터 내 평어함까지 단계별 사용법과 실제 활용 요령을 확인할 수 있습니다.

같은 키워드라도 문장이 똑같이 반복되지 않도록 구성했습니다.

동일한 키워드와 수준을 선택하더라도 학생별 평어가 가능한 한 서로 다른 문장으로 생성되도록 문장 구조·서술 순서·표현을 다양화하는 방식을 적용했습니다. 다만 AI 생성 결과가 항상 완벽하다고 보장할 수는 없으므로, 최종 사용 전에는 모든 문장을 한 번씩 읽어 사실관계·표현·중복 여부에 문제가 없는지 확인해 주세요.

학생 선택

5학년 행동특성 및 종합의견은 일상적인 학교생활에서 반복적으로 관찰한 행동과 변화 과정을 학생별로 구분해 기록하는 것이 중요합니다.

기능 설명

한 학생 모드와 여러 학생 일괄 모드를 지원합니다. 여러 학생을 선택하면 ‘학생별 추가 기술’을 펼쳐 같은 행동 키워드를 사용하더라도 학생별 실제 장면을 따로 입력할 수 있습니다.

활용 요령

여러 학생에게 공통으로 관찰한 학급 상황은 교사 자유 기술에 적고, 학생마다 다른 변화나 구체적 행동은 학생별 추가 기술에 나누어 적으세요.

실제 예시

예: 같은 책임감 영역을 보더라도 한 학생은 ‘맡은 일 확인’, 다른 학생은 ‘끝까지 수행’이 두드러졌다면 실제 관찰 장면을 각각 다르게 기록합니다.

주의사항

같은 학급 활동에 참여했다고 모든 학생에게 같은 행동 특성을 적용하지 마세요. 한두 번의 사건만으로 성격을 단정하지 말고 반복적으로 확인된 행동과 변화 중심으로 적습니다.

키워드 선택

행발 키워드는 교과 성취수준이 아니라 관찰한 행동을 강점·변화·성장·지원 필요의 방향으로 정리하는 도구입니다.

기능 설명

행동 영역별 키워드를 좌클릭하면 강점 → 변화·성장 → 지원 필요 → 해제 순으로 바뀝니다. 성장 지원 영역의 키워드는 지원 필요 방향으로만 반영됩니다. 별도의 하위 키워드 구조는 없습니다.

활용 요령

자기관리, 책임감, 학습태도, 주도성, 의사소통, 관계, 협력, 규칙, 감정조절, 도전, 창의성, 성찰 등에서 실제로 관찰한 핵심 행동만 선택하세요. 우클릭하면 선택 방향을 한 번에 해제할 수 있습니다.

실제 예시

예: 책임감·성실성의 ‘끝까지 수행’은 강점으로, 성찰·성장의 ‘행동 돌아보기’가 이전보다 늘었다면 변화·성장 방향으로 선택할 수 있습니다.

주의사항

지원 필요를 이미 성취한 강점처럼 바꾸지 마세요. ‘게으름’, ‘이기적임’처럼 성격을 단정하는 표현 대신 관찰 가능한 행동과 필요한 지원을 중심으로 기록합니다.

문장 수

행발은 많은 키워드를 나열하기보다 학생을 잘 보여 주는 행동 몇 가지를 서로 다른 문장으로 정리하는 편이 자연스럽습니다.

기능 설명

학생당 1~5문장을 설정할 수 있습니다. 핵심 행동 하나면 1문장, 강점과 변화 과정 또는 서로 다른 생활 영역을 함께 기록하려면 2~3문장이 적합합니다.

활용 요령

비슷한 키워드는 한 문장에 묶고, 책임감과 관계·협력처럼 성격이 다른 행동은 문장을 나누세요. 키워드를 많이 골랐다고 모두 결과에 넣을 필요는 없습니다.

실제 예시

예: ‘맡은 일을 끝까지 수행함’과 ‘갈등 후 상대 이야기를 듣고 행동을 조정함’은 서로 다른 영역이므로 2문장으로 나누면 학생의 모습이 더 분명해집니다.

주의사항

문장 수를 채우기 위해 관찰하지 않은 행동을 추가하지 마세요. 지원이 필요한 내용은 낙인 없이 현재 모습과 성장 방향이 함께 드러나도록 검토합니다.

AI 평어 생성

5학년 행발은 실제 학교생활에서 보인 자기관리, 관계, 공동체 참여, 성찰과 변화 등을 관찰 근거에 따라 종합하는 것이 핵심입니다.

문장 다양화 기능

같은 키워드를 여러 학생에게 사용해도 가능한 한 같은 문장을 그대로 반복하지 않도록 생성 과정에서 표현과 문장 구조를 달리하도록 구성되어 있습니다. 그래도 학생별 실제 관찰 근거가 다르면 학생별 추가 기술에 그 차이를 적어 주는 것이 가장 효과적입니다.

기능 설명

교사 자유 기술, 일괄 모드의 학생별 추가 기술, 선택한 행동 키워드와 방향, 참고 문서의 파일명·문서별 참고 지침을 바탕으로 Gemini API가 종합의견 초안을 생성합니다.

활용 요령

‘모둠 활동에서 역할을 확인하고 끝까지 수행함’, ‘친구 의견을 듣고 자신의 말을 조절하는 모습이 늘어남’처럼 행동과 변화를 구체적으로 적으세요.

실제 예시

예: ‘처음에는 발표 준비를 미루는 경우가 있었으나 최근에는 해야 할 일을 확인하고 스스로 시작하는 모습이 늘어남’처럼 변화 과정을 자유 기술에 적고 관련 키워드를 선택합니다.

주의사항

교사의 실제 관찰 기록이 가장 중요한 근거이며 AI 결과는 초안입니다. 현재 직접 API 호출은 첨부 파일 본문을 자동 전송하지 않고 파일명과 문서별 참고 지침을 반영합니다. 학생의 마음·의도·성격을 근거 없이 추정하거나, 관찰하지 않은 행동을 만들어 내지 않았는지 반드시 확인하세요.

AI가 만든 종합의견은 내 평어함에서 학생별로 다시 읽고 수정한 뒤 교사가 최종 확정합니다.

활용 요령

강점·성장·지원 필요가 실제 관찰과 맞는지 학생별로 확인하고, 수정한 내용은 빨간 수정 저장 버튼 또는 전체 수정 저장으로 확정하세요. Excel 저장과 JSON 백업·복원도 사용할 수 있습니다.

실제 예시

예: 생성 결과를 평어함에 추가 → 성격처럼 단정된 표현이 없는지 수정 → 중복 문장 검사 → 전체 수정 저장 → 행동특성 Excel 저장 순으로 마무리합니다.
