자료 구성 및 출처 안내

창체 키워드는 2학년 학교생활에서 관찰 가능한 활동·참여·협력 장면을 중심으로 AI가 재구성한 참고 요소입니다. 특정 평어 예시집의 완성 문장을 그대로 수록하지 않았습니다. 참고용 평어 자료의 완성 문장을 코드에 그대로 탑재하지 않고, 의미 요소를 키워드·관찰 근거로 재구성했습니다. 실제 기록은 학교의 창체 운영 내용과 학생의 실제 참여 모습, 교사의 관찰 기록을 우선해 확인·수정해 주세요.

활용 팁

[2학년-2학기]놀퀴즈 창체 평어생성기 활용 팁

기능을 단계별로 확인하고, 실제 관찰·평가 기록에 맞게 활용하세요.

같은 키워드라도 문장이 똑같이 반복되지 않도록 구성했습니다.

동일한 키워드와 수준을 선택하더라도 학생별 평어가 가능한 한 서로 다른 문장으로 생성되도록 문장 구조·서술 순서·표현을 다양화하는 방식을 적용했습니다. 다만 AI 생성 결과가 항상 완벽하다고 보장할 수는 없으므로, 최종 사용 전에는 모든 문장을 한 번씩 읽어 사실관계·표현·중복 여부에 문제가 없는지 확인해 주세요.

2학년 창체는 활동 참여 장면이 구체적으로 드러나도록 학생별 역할·협력·표현 모습을 구분해 기록하는 것이 좋습니다.

기능 설명

한 학생 모드는 한 명을 집중해서 작성하고, 여러 학생 일괄 모드는 같은 기준을 여러 학생에게 적용할 때 사용합니다. 일괄 모드에서는 선택한 학생이 여러 명일 때 학생별 추가 기술을 펼칠 수 있습니다.

활용 요령

공통 수업·활동 내용은 키워드와 교사 자유 기술에 두고, 학생마다 다른 수행·관찰 내용은 학생별 추가 기술에 나누어 적으세요.

실제 예시

같은 합창 활동에 참여했더라도 학생별 추가 기술에 “친구 소리를 들으며 부름”, “시작과 끝을 맞추는 연습에 꾸준히 참여함”처럼 실제 참여 모습을 다르게 적습니다.

주의사항

일괄 생성이라고 해서 모든 학생에게 같은 관찰 내용을 넣지 마세요. 실제 수행이 다른 학생은 개별 기록을 구분해야 결과도 달라집니다.

창체는 자율·자치활동, 동아리활동, 진로활동의 실제 영역과 활동 키워드를 사용하며, 선택한 상위 활동에만 전용 하위 키워드가 연결됩니다.

기능 설명

상·하위 활동 키워드는 매우 잘함 → 잘함 → 보통 → 해제 순으로 바뀝니다. 각 영역의 활동 단위에는 실제 활동명 추가 입력란이 있습니다.

활용 요령

활동 자체를 선택하는 데 그치지 말고 학생이 실제로 한 역할·협력·참여 행동을 하위 키워드로 구체화하세요. 실제 동아리명이나 행사명이 있다면 활동명에 적을 수 있습니다.

실제 예시

동아리의 “보드게임 활동”을 선택한 뒤 실제 관찰에 따라 “게임 규칙 이해하기”, “차례 지키기” 등을 하위 근거로 선택할 수 있습니다.

주의사항

상위 활동 우클릭 시 그 활동에 연결된 하위 키워드도 함께 해제됩니다. 실제로 하지 않은 동아리·행사·활동명을 새로 만들어 입력하지 마세요.

학생당 평어 문장 수는 1~5문장으로 설정할 수 있습니다. 문장 수는 키워드 개수보다 “서로 다른 핵심 근거가 몇 가지인지”를 기준으로 정하는 편이 좋습니다.

기능 설명

1문장은 핵심 관찰이 한 가지일 때 적합하고, 2~3문장은 서로 다른 수행이나 행동을 구분해 기록할 때 유용합니다.

활용 요령

키워드를 많이 선택했더라도 모두 한 문장에 넣지 마세요. 비슷한 근거는 묶고, 성격이 다른 내용은 문장을 나누는 편이 자연스럽습니다.

실제 예시

한 활동에서 참여 모습만 핵심이면 1문장, 역할 수행과 협력·표현 모습이 서로 다르면 2~3문장으로 나누는 편이 자연스럽습니다.

주의사항

선택한 모든 키워드를 결과에 반드시 넣는 것이 좋은 것은 아닙니다. 문장 수보다 근거의 정확성과 자연스러운 서술을 우선하세요.

AI 평어 만들기는 선택한 키워드와 교사가 입력한 근거를 바탕으로 초안을 생성합니다. 2학년에서는 추상적인 평가보다 실제로 확인된 짧고 구체적인 수행·행동을 우선하는 것이 적절합니다.

문장 다양화 기능

같은 키워드를 여러 학생에게 사용해도 가능한 한 같은 문장을 그대로 반복하지 않도록 생성 과정에서 표현과 문장 구조를 달리하도록 구성되어 있습니다. 그래도 학생별 실제 관찰 근거가 다르면 학생별 추가 기술에 그 차이를 적어 주는 것이 가장 효과적입니다.

기능 설명

  • 교사 자유 기술: 실제 관찰·평가 내용을 입력합니다.
  • 학생별 추가 기술: 일괄 모드에서 학생마다 다른 근거를 입력합니다.
  • 실제 활동명: 해당 단원·활동에서 실제로 한 활동 이름이 있을 때만 입력합니다.
  • 참고 문서: 파일명과 문서별 참고 지침을 관리할 수 있습니다.

활용 요령

교사가 직접 입력한 실제 관찰·평가 기록을 가장 중요한 근거로 사용하세요. 생성 결과는 최종 기록이 아니라 검토·수정을 위한 초안입니다.

실제 예시

예: 동아리 활동에서 실제 활동명을 “보드게임 활동”으로 적고, 교사 자유 기술에 “규칙을 확인한 뒤 차례를 지키며 친구와 참여함”처럼 관찰 장면을 덧붙일 수 있습니다.

주의사항

현재 직접 Gemini API 호출 구조에서는 선택한 파일의 본문이 자동으로 API에 전송되지 않고 파일명과 참고 지침이 생성 지침에 반영됩니다. 파일 내용을 실제 근거처럼 추정하지 말고, 수행하지 않은 활동·확인되지 않은 성취나 학생의 마음·의도·성격이 만들어지지 않았는지 반드시 확인하세요.

내 평어함은 AI가 만든 문장을 바로 확정하는 곳이 아니라, 학생별 기록을 교사가 최종 확인·수정하고 저장·내보내는 작업 공간입니다.

자동 문장 다양화와 중복 확인 기능이 적용되어 있어도 최종 판단은 교사의 몫입니다. 내 평어함으로 옮긴 뒤 학생별 문장을 한 번씩 읽어 실제 관찰 내용과 맞는지, 지나치게 비슷한 문장이나 어색한 표현은 없는지 확인한 후 사용해 주세요.

내 평어함 이동 확인

평어를 옮기면 저장 완료 팝업에서 실제로 저장된 최종 내용을 바로 확인할 수 있습니다. ‘기존 평어함 지우고 붙이기’는 기존 내용이 있을 경우 먼저 기존 평어와 새 평어를 함께 보여 주며, 교체 여부를 확인한 뒤 실행됩니다.

기능 설명

생성 결과는 기존 평어함 지우고 붙이기 또는 평어함 뒤에 이어붙이기로 옮길 수 있습니다. 내 평어함에서는 학생별 편집, 문장별 편집, 저장 전 변경 표시, 전체 수정 저장을 사용할 수 있습니다.

활용 요령

같은 문장 검사·다르게 만들기는 완전히 동일한 문장만 검사합니다. 최종 확인 후 현재/전체 Excel 저장, JSON 전체 작업 백업·복원, Excel 평어 복원 기능을 활용할 수 있습니다.

실제 예시

창체 영역별 생성 결과를 내 평어함에 옮긴 뒤 학생별 문장을 수정하고, 필요하면 동일 문장 검사로 완전히 같은 문장만 찾아 다르게 만들 수 있습니다.

주의사항

AI 생성 결과를 그대로 확정하지 말고 반드시 학생의 실제 기록과 대조하세요. 내 평어함에서 수정한 내용은 저장 전 변경 상태를 확인한 뒤 수정 저장 또는 전체 수정 저장으로 확정합니다.
