4학년 2학기 교과 평어 활용 팁
4학년의 실제 학습 과정과 교사 관찰을 중심으로, 필요한 기능만 단계별로 확인하세요.
같은 키워드라도 문장이 똑같이 반복되지 않도록 구성했습니다.
동일한 키워드와 수준을 선택하더라도 학생별 평어가 가능한 한 서로 다른 문장으로 생성되도록 문장 구조·서술 순서·표현을 다양화하는 방식을 적용했습니다. 다만 AI 생성 결과가 항상 완벽하다고 보장할 수는 없으므로, 최종 사용 전에는 모든 문장을 한 번씩 읽어 사실관계·표현·중복 여부에 문제가 없는지 확인해 주세요.
한 학생을 자세히 기록하거나, 같은 수업·평가 기준을 여러 학생에게 적용해 일괄 생성할 수 있습니다.
기능 설명
한 학생 모드에서는 한 번호를 선택하고, 여러 학생 일괄 모드에서는 여러 번호를 함께 선택하거나 전체 선택 버튼으로 한 번에 선택·해제합니다. 일괄 모드에서 2명 이상을 선택하면 ‘학생별 추가 기술’을 펼칠 수 있습니다.
활용 요령
공통으로 관찰한 수업·평가 내용은 교사 자유 기술에 적고, 학생마다 다른 수행은 학생별 추가 기술에 나누어 적으면 결과가 덜 획일적입니다.
4학년 예시
같은 수학 수업이라도 1번은 ‘진분수 덧셈 계산 과정을 설명함’, 2번은 ‘계산은 수행하나 결과 점검에 안내가 필요함’처럼 실제 차이를 학생별로 기록할 수 있습니다.
주의사항
여러 학생에게 같은 키워드를 선택했다는 이유만으로 동일한 관찰 내용을 복사하지 마세요. 학생별 실제 수행 차이는 교사가 확인해야 합니다.
교과는 상위 평가 키워드와 하위 세부 키워드를 조합해 학습 근거를 고릅니다.
기능 설명
상위·하위 키워드는 지식·이해, 과정·기능, 가치·태도 범주를 포함할 수 있으며, 좌클릭할 때 매우 잘함 → 잘함 → 보통 → 못함 → 매우 못함 → 해제 순으로 바뀝니다.
활용 요령
상위 키워드로 큰 평가 요소를 고른 뒤, 실제로 관찰한 하위 수행만 추가 선택하세요. 우클릭하면 현재 수준과 관계없이 바로 해제되며 상위 우클릭 시 연결 하위도 함께 해제됩니다.
4학년 예시
수학 ‘분수의 덧셈과 뺄셈’에서 ‘진분수의 덧셈 계산’을 고른 뒤 ‘분모가 같은 진분수의 덧셈을 정확하게 계산하기’처럼 실제 수행에 맞는 하위 근거를 선택할 수 있습니다.
주의사항
키워드가 많다고 좋은 평어가 되는 것은 아닙니다. 국어·수학·사회·과학 등 서로 다른 수행을 한 문장에 억지로 섞지 마세요.
학생당 평어 문장 수는 1~5문장으로 설정할 수 있습니다.
기능 설명
문장 수 입력값에 맞춰 AI가 정확한 문장 수를 목표로 생성하며 결과 카드에서 현재 문장 수와 글자 수를 확인할 수 있습니다.
활용 요령
하나의 뚜렷한 수행만 기록할 때는 1문장, 개념 이해와 수행 과정처럼 서로 다른 근거가 있을 때는 2~3문장이 보통 읽기 좋습니다.
4학년 예시
과학 ‘달의 생김새 관찰’과 ‘관찰한 달의 모습을 그림이나 말로 나타내기’를 함께 기록한다면 관찰과 표현을 2문장으로 나누는 방식이 자연스럽습니다.
주의사항
선택한 모든 키워드를 반드시 결과에 넣을 필요는 없습니다. 서로 관련 없는 근거를 한 문장에 몰아넣지 않는 것이 우선입니다.
AI는 선택 근거와 교사 기록을 바탕으로 초안을 만들며, 최종 판단과 수정은 교사가 합니다.
문장 다양화 기능
같은 키워드를 여러 학생에게 사용해도 가능한 한 같은 문장을 그대로 반복하지 않도록 생성 과정에서 표현과 문장 구조를 달리하도록 구성되어 있습니다. 그래도 학생별 실제 관찰 근거가 다르면 학생별 추가 기술에 그 차이를 적어 주는 것이 가장 효과적입니다.
기능 설명
교사 자유 기술, 일괄 모드의 학생별 추가 기술, 선택 키워드·수준, 참고 문서의 파일명과 문서별 참고 지침이 생성 지침에 반영됩니다. 문장 표현은 보통·간결하게·구체적으로 중 선택할 수 있습니다.
활용 요령
실제 수행을 가장 구체적으로 적을 수 있는 곳은 교사 자유 기술과 학생별 추가 기술입니다. 참고 문서는 ‘이 문서에서 우선 참고할 내용’에 필요한 항목을 짧게 적어 주세요.
4학년 예시
사회 ‘민주주의와 자치’에서 학생이 학급회의 사례를 찾아 설명한 실제 모습이 있었다면 그 관찰 내용을 자유 기술에 적고 관련 키워드를 보조 근거로 선택합니다.
주의사항
AI 결과는 최종 기록이 아니라 초안입니다. 수행하지 않은 활동, 확인되지 않은 성취, 학생의 마음·의도·성격 추정이 섞이지 않았는지 반드시 확인하세요. 첨부 파일 내용은 Canvas 실행 환경에서 AI에 실제 제공된 경우에만 참고할 수 있습니다.
생성 결과를 내 평어함으로 옮긴 뒤 교사가 최종 확인·수정·저장하는 단계입니다.
마지막으로 한 번 읽어보기
자동 문장 다양화와 중복 확인 기능이 적용되어 있어도 최종 판단은 교사의 몫입니다. 내 평어함으로 옮긴 뒤 학생별 문장을 한 번씩 읽어 실제 관찰 내용과 맞는지, 지나치게 비슷한 문장이나 어색한 표현은 없는지 확인한 후 사용해 주세요.
내 평어함 이동 확인
평어를 옮기면 저장 완료 팝업에서 실제로 저장된 최종 내용을 바로 확인할 수 있습니다. ‘기존 평어함 지우고 붙이기’는 기존 내용이 있을 경우 먼저 기존 평어와 새 평어를 함께 보여 주며, 교체 여부를 확인한 뒤 실행됩니다. 저장 완료 뒤 ‘다음 학생 작성’을 누르면 현재 키워드 선택을 비우고 학생 선택 영역으로 즉시 이동해 다음 기록을 이어갈 수 있습니다.
기능 설명
결과 카드에서 기존 평어함을 지우고 붙이거나 뒤에 이어붙일 수 있습니다. 내 평어함에서는 직접 수정, 전체 AI 재생성, 문장별 AI 재생성, 글자 수·문장 수 줄이기를 사용할 수 있습니다.
활용 요령
수정한 행은 ‘수정 저장 필요’로 표시됩니다. 여러 행을 고쳤다면 ‘전체 수정 저장’을 사용하고, ‘같은 문장 검사·다르게 만들기’로 학생 간 완전 동일 문장을 확인할 수 있습니다.
저장 예시
최종 확인 후 현재 평어함 Excel 또는 전체 Excel로 저장할 수 있고, 작업 상태까지 보관하려면 전체 작업 JSON 백업을 사용합니다. JSON·Excel 복원도 지원합니다.
주의사항
AI로 다시 만들거나 문장을 줄인 결과도 자동 확정되는 것이 아닙니다. 빨간 ‘수정 저장 필요’ 상태를 확인하고 교사가 검토한 뒤 저장하세요.
