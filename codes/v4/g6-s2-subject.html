단계별 활용 가이드

[6학년-2학기] 놀평어 교과 평어생성기 활용 팁

기본 흐름에 따라 필요한 단계만 선택해 확인하세요. 실제 학생의 관찰·평가 기록이 항상 가장 우선입니다.

같은 키워드라도 문장이 똑같이 반복되지 않도록 구성했습니다.

동일한 키워드와 수준을 선택하더라도 학생별 평어가 가능한 한 서로 다른 문장으로 생성되도록 문장 구조·서술 순서·표현을 다양화하는 방식을 적용했습니다. 다만 AI 생성 결과가 항상 완벽하다고 보장할 수는 없으므로, 최종 사용 전에는 모든 문장을 한 번씩 읽어 사실관계·표현·중복 여부에 문제가 없는지 확인해 주세요.

1. 학생 선택

한 학생 또는 여러 학생을 먼저 선택합니다. 6학년은 수행 내용이 다양하므로 학생별 실제 관찰 근거를 구분해 두는 것이 중요합니다.

한 학생

한 명의 키워드와 관찰 기록을 세밀하게 조정할 때 적합합니다.

여러 학생 일괄

같은 단원·평가 기준으로 여러 학생의 초안을 만들 때 편리합니다.

활용 요령

일괄 생성에서도 학생별 추가 기술에 서로 다른 수행 모습이나 오류·강점을 짧게 적으면 결과가 훨씬 구체적입니다.

예시

“분수의 나눗셈에서 계산 원리를 말로 설명함”, “토의에서 근거 자료를 찾아 의견을 보완함”처럼 확인 가능한 장면을 적습니다.

주의

번호만 여러 명 선택하고 개별 근거가 전혀 없으면 학생별 차이가 충분히 드러나지 않을 수 있습니다.

2. 키워드 선택

교과·단원을 고른 뒤 상위 키워드와 필요한 하위 키워드를 선택합니다. 6학년은 단순 참여보다 설명·추론·적용 같은 고학년 수행 근거를 함께 보는 것이 좋습니다.

상위 키워드

평가하고 싶은 핵심 학습 내용이나 수행을 선택합니다.

하위 키워드

지식·이해, 과정·기능, 가치·태도 중 실제로 관찰한 세부 근거를 추가합니다.

활용 요령

키워드는 많이 고르는 것보다 실제 학생 수행을 잘 설명하는 2~5개 정도의 핵심 근거를 우선하는 편이 자연스럽습니다.

예시

상위 “비례식을 활용해 문제 해결” + 하위 “조건에 맞는 비례식 세우기”, “해결 과정을 설명하기”처럼 연결합니다.

주의

선택하지 않은 수행이나 실제로 하지 않은 활동을 평어에 넣기 위해 키워드를 임의로 추가하지 마세요.

3. 문장 수

선택한 근거의 양에 맞춰 학생별 생성 문장 수를 정합니다.

1문장

핵심 성취 한 가지를 간결하게 기록할 때 적합합니다.

2~3문장

서로 다른 수행이나 지식·과정·태도를 나누어 기록할 때 적합합니다.

활용 요령

키워드가 많다면 문장 수를 조금 늘리거나 키워드를 줄이세요. AI가 모든 키워드를 억지로 한 문장에 넣지 않도록 하는 것이 좋습니다.

예시

개념 이해 1문장 + 문제 해결 과정 1문장처럼 문장 역할을 나누면 중복이 줄어듭니다.

주의

짧은 기록에 너무 많은 키워드를 선택하면 문장이 길고 나열식이 될 수 있습니다.

4. AI 평어 생성

키워드, 교사 자유 기술, 학생별 추가 기술, 활동명과 참고 문서를 근거로 AI 평어를 생성합니다.

문장 다양화 기능

같은 키워드를 여러 학생에게 사용해도 가능한 한 같은 문장을 그대로 반복하지 않도록 생성 과정에서 표현과 문장 구조를 달리하도록 구성되어 있습니다. 그래도 학생별 실제 관찰 근거가 다르면 학생별 추가 기술에 그 차이를 적어 주는 것이 가장 효과적입니다.

교사 자유 기술

실제 관찰·평가 내용을 가장 우선적인 근거로 입력합니다.

참고 문서

필요하면 문서별로 어떤 부분을 우선 참고할지 지침을 적습니다.

활용 요령

생성된 문장은 초안입니다. 6학년의 실제 수행 수준과 맞는지, 과장된 표현이나 근거 없는 활동이 없는지 반드시 확인하세요.

예시

“발표 자료에서 두 근거를 비교함”처럼 관찰 사실을 입력하면 추상적인 “논리적임”보다 구체적인 평어가 나옵니다.

주의

AI가 학생의 마음·의도나 확인되지 않은 성취를 추정한 문장은 그대로 사용하지 마세요.

5. 내 평어함

생성 결과를 확인·수정한 뒤 학생별 내 평어함으로 옮겨 최종 기록을 관리합니다.

추가/교체

기존 문장을 유지해 추가하거나 현재 문장을 교체할 수 있습니다.

최종 관리

학생별 문장을 수정하고 중복을 확인한 뒤 Excel/JSON으로 저장·백업합니다.

활용 요령

생성 직후 바로 내보내기보다 내 평어함에서 학생 간 문장 중복, 표현 과장, 사실관계를 한 번 더 확인하세요.

예시

같은 성취기준을 평가했더라도 학생별 실제 근거가 다르면 문장 시작과 핵심 서술어도 달라지게 정리합니다.

주의

내 평어함으로 옮겼다고 자동으로 최종 기록이 되는 것은 아닙니다. 교사의 최종 검토가 필요합니다.

내 평어함 이동 확인

평어를 옮기면 저장 완료 팝업에서 실제로 저장된 최종 내용을 바로 확인할 수 있습니다. ‘기존 평어함 지우고 붙이기’는 기존 내용이 있을 경우 먼저 기존 평어와 새 평어를 함께 보여 주며, 교체 여부를 확인한 뒤 실행됩니다.
