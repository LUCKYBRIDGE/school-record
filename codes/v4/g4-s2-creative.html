활동명 맥락 선택 · 1~2개 권장

활동명은 어떤 활동에서 있었던 일인지 알려 주는 맥락입니다. 실제 평가는 아래 관찰 행동 키워드와 교사 기록을 근거로 합니다.

특정 브랜드·제품·서비스명은 기본적으로 교육적 활동을 나타내는 일반 명칭으로 바꾸어 사용합니다.
최근 사용 활동
활동명은 맥락이고 관찰 행동은 평가 근거입니다. 활동명만 선택했다고 특정 행동을 AI가 임의로 만들어 내지 않습니다.
활동명 관련 관찰 행동 추천
활동명을 선택하면 관련 키워드를 우선 표시합니다. 추천은 자동 선택되지 않습니다.

4학년 2학기 창체 평어 활용 팁
실제 참여·역할·협력·탐구·진로 활동이 드러나도록 학생별 근거를 구분해 기록하세요.
같은 키워드라도 문장이 똑같이 반복되지 않도록 구성했습니다.
동일한 키워드와 수준을 선택하더라도 학생별 평어가 가능한 한 서로 다른 문장으로 생성되도록 문장 구조·서술 순서·표현을 다양화하는 방식을 적용했습니다. 다만 AI 생성 결과가 항상 완벽하다고 보장할 수는 없으므로, 최종 사용 전에는 모든 문장을 한 번씩 읽어 사실관계·표현·중복 여부에 문제가 없는지 확인해 주세요.
한 학생의 활동을 자세히 기록하거나, 같은 창체 활동에 참여한 여러 학생을 함께 생성할 수 있습니다.
기능 설명
한 학생/여러 학생 일괄 모드를 지원합니다. 일괄 모드에서 여러 번호를 선택하면 ‘학생별 추가 기술’을 펼쳐 학생마다 다른 역할·참여 모습을 적을 수 있습니다.
활용 요령
행사명이나 동아리명처럼 공통 맥락은 교사 자유 기술에 적고, 학생마다 맡은 역할이나 수행이 다르면 학생별 추가 기술에 구분해 적으세요.
4학년 예시
같은 학급 자치 활동에서도 1번은 회의 안건을 제안하고, 2번은 친구 의견을 정리해 합의 과정에 참여했다면 각각 다른 학생별 기록을 넣습니다.
주의사항
일괄 생성은 편의 기능이지 학생별 관찰을 동일하게 만드는 기능이 아닙니다. 실제 참여 모습이 다른 학생에게 같은 근거를 복사하지 마세요.
활동명으로 맥락을 고르고, 실제로 관찰한 행동 키워드와 수준을 선택합니다.
활동명과 관찰 키워드는 다릅니다
활동명은 ‘어떤 활동에서 있었던 일인지’를 알려 주고, 관찰 키워드는 ‘그 활동에서 학생이 실제로 무엇을 했는지’를 알려 줍니다. 활동명만 선택했다고 해서 특정 행동을 AI가 임의로 만들어 내지는 않습니다.
기능 설명
활동명은 최대 2개까지 선택할 수 있고 수준을 매기지 않습니다. 관찰 행동 키워드는 좌클릭으로 매우 잘함 → 잘함 → 보통 → 해제 순으로 바뀌며 우클릭하면 즉시 해제됩니다.
활용 요령
활동명 1개 + 핵심 관찰 행동 2~4개 정도를 우선 권장합니다. 활동명을 고르면 관련 관찰 행동이 추천·우선 정렬되지만 자동으로 선택되지는 않습니다.
4학년 예시
‘학급 임원 선거’를 고른 뒤 후보 의견 듣기·투표 절차 지키기처럼 실제로 본 행동을 선택하거나, ‘직업인 인터뷰’에서 질문 준비·정보 기록처럼 확인한 행동을 선택합니다.
주의사항
선택하거나 직접 입력하지 않은 구체적인 활동명·행사명은 AI가 임의로 만들지 않습니다. 기본 활동명은 특정 회사·브랜드·제품·서비스가 아닌 교육 목적과 수행 방식 중심의 일반 명칭을 사용합니다.
학생당 1~5문장을 설정할 수 있으며, 활동 근거의 수와 성격에 따라 나누는 것이 좋습니다.
기능 설명
설정한 문장 수에 맞춰 AI가 결과를 생성하고 결과 카드에서 문장 수와 글자 수를 확인할 수 있습니다.
활용 요령
역할 수행 한 가지를 기록하면 1문장, 참여 과정과 협력·성찰처럼 성격이 다른 근거가 있으면 2~3문장으로 나누는 편이 자연스럽습니다.
4학년 예시
과학·메이커·코딩 동아리에서 탐구 방법을 정한 과정과 결과를 비교·해석한 모습을 모두 기록한다면 각각의 수행을 문장으로 나눌 수 있습니다.
주의사항
선택한 키워드가 많아도 모두 문장에 넣지 않습니다. 활동의 핵심 근거가 흐려질 정도로 문장을 늘리지 마세요.
창체 평어는 실제 활동 참여와 역할을 교사 기록으로 확인한 뒤 AI 초안을 검토하는 방식이 안전합니다.
문장 다양화 기능
같은 키워드를 여러 학생에게 사용해도 가능한 한 같은 문장을 그대로 반복하지 않도록 생성 과정에서 표현과 문장 구조를 달리하도록 구성되어 있습니다. 그래도 학생별 실제 관찰 근거가 다르면 학생별 추가 기술에 그 차이를 적어 주는 것이 가장 효과적입니다.
기능 설명
교사 자유 기술, 학생별 추가 기술, 선택한 창체 키워드·수준, 참고 문서 파일명과 문서별 지침을 바탕으로 생성합니다. 문장 표현도 선택할 수 있습니다.
활용 요령
실제 활동명은 교사 자유 기술에 적고, 그 활동에서 학생이 맡은 역할·협력 방식·탐구 과정·발표 모습을 구체적으로 덧붙이세요.
4학년 예시
‘학교 축제 준비에서 안내판 제작 역할을 맡아 친구와 내용을 조정함’처럼 확인 가능한 참여 장면을 적으면 키워드보다 강한 근거가 됩니다.
주의사항
AI 결과는 초안입니다. 참여하지 않은 행사나 맡지 않은 역할, 확인되지 않은 주도성·관심·마음을 만들어 내지 않았는지 확인하세요. 첨부 파일 내용은 실행 환경에서 AI에 실제 제공된 경우에만 참고됩니다.
생성 결과는 내 평어함에 옮긴 뒤 학생별로 다듬고 최종 저장합니다.
마지막으로 한 번 읽어보기
자동 문장 다양화와 중복 확인 기능이 적용되어 있어도 최종 판단은 교사의 몫입니다. 내 평어함으로 옮긴 뒤 학생별 문장을 한 번씩 읽어 실제 관찰 내용과 맞는지, 지나치게 비슷한 문장이나 어색한 표현은 없는지 확인한 후 사용해 주세요.
내 평어함 이동 확인
평어를 옮기면 저장 완료 팝업에서 실제로 저장된 최종 내용을 바로 확인할 수 있습니다. ‘기존 평어함 지우고 붙이기’는 기존 내용이 있을 경우 먼저 기존 평어와 새 평어를 함께 보여 주며, 교체 여부를 확인한 뒤 실행됩니다. 저장 완료 뒤 ‘다음 학생 작성’을 누르면 현재 키워드 선택을 비우고 학생 선택 영역으로 즉시 이동해 다음 기록을 이어갈 수 있습니다.
기능 설명
기존 평어함을 지우고 붙이기/뒤에 이어붙이기를 지원하며, 내 평어함에서 직접 수정, 전체·문장별 AI 재생성, 글자 수·문장 수 줄이기를 할 수 있습니다.
활용 요령
수정 후 빨간 ‘수정 저장 필요’를 확인하세요. 동일 문장 검사는 완전히 같은 문장만 찾아 필요한 학생 문장을 다르게 만들도록 돕습니다.
저장 예시
영역별 현재 평어함 Excel, 전체 Excel, Excel 백업 ZIP, CSV, 전체 작업 JSON 백업을 저장할 수 있고 JSON·Excel 복원을 지원합니다.
주의사항
내 평어함으로 옮긴 문장도 최종 기록이 아닙니다. 실제 활동과 맞는지 교사가 마지막으로 확인하고 수정 저장해야 합니다.
