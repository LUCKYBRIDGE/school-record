활용 팁

같은 키워드라도 문장이 똑같이 반복되지 않도록 구성했습니다.

동일한 키워드와 수준을 선택하더라도 학생별 평어가 가능한 한 서로 다른 문장으로 생성되도록 문장 구조·서술 순서·표현을 다양화하는 방식을 적용했습니다. 다만 AI 생성 결과가 항상 완벽하다고 보장할 수는 없으므로, 최종 사용 전에는 모든 문장을 한 번씩 읽어 사실관계·표현·중복 여부에 문제가 없는지 확인해 주세요.

학생을 어떻게 나누어 생성할지 먼저 정하면 같은 기준을 쓰면서도 학생별 실제 모습을 구분하기 쉽습니다.

기능 설명

학생 수는 1~30명으로 설정할 수 있고, ‘한 학생’과 ‘여러 학생 일괄’ 모드를 사용할 수 있습니다. ‘전체 선택’은 한 학생·여러 학생 일괄 모드와 관계없이 항상 표시됩니다. 한 번 누르면 현재 학생을 모두 선택하고, 다시 누르면 전체 선택을 해제합니다. 전체 선택 시 자동으로 여러 학생 일괄 모드로 전환되며, 2명 이상 선택하면 ‘학생별 추가 기술’을 펼칠 수 있습니다.

활용 요령

같은 기준으로 여러 학생을 생성할 때 공통 키워드는 함께 선택하되, 학생마다 실제 수행이나 관찰 장면이 다르면 학생별 추가 기술에 구분해 적으세요.

실제 예시

예: 같은 동아리 활동에 참여했더라도 한 학생은 역할을 나누어 협력했고 다른 학생은 발표 준비를 꾸준히 했다면, 학생별 추가 기술에 각자의 실제 참여 모습을 구분해 적습니다.

주의사항

일괄 모드의 교사 자유 기술은 선택 학생에게 공통 근거로 사용됩니다. 특정 학생에게만 해당하는 사실을 공통 기술에 적지 마세요.

3학년 창체 파일은 자율·자치활동, 동아리활동, 진로활동 영역과 각 활동에 맞는 상위·하위 활동 키워드를 사용합니다.

활동명과 관찰 키워드는 다릅니다

활동명은 어떤 활동에서 있었던 일인지 알려 주는 맥락이고, 관찰 키워드는 그 활동에서 학생이 실제로 무엇을 했는지 보여 주는 평가 근거입니다. 활동명만 선택했다고 특정 행동을 AI가 만들어 내지 않습니다. 활동명 1개와 핵심 관찰 행동 2~4개 정도가 가장 사용하기 편합니다.

기능 설명

상위·하위 활동 키워드는 매우 잘함 → 잘함 → 보통 → 해제 순으로 선택됩니다. 자율·자치, 동아리, 진로 영역을 바꾸어 해당 활동 키워드를 선택할 수 있습니다.

활용 요령

실제 참여한 영역을 먼저 고른 뒤 핵심 활동 키워드와 필요한 하위 키워드만 선택하세요. 상위 우클릭은 연결 하위까지, 하위 우클릭은 해당 항목만 해제합니다.

실제 예시

‘학급회의 참여’, ‘2학기 시작·개학’, ‘학급 임원 선거 참여’, ‘노래·합창’, ‘블록코딩’, ‘주변의 직업 탐색’처럼 현재 파일에 있는 실제 활동 범주에서 학생이 참여한 것만 선택합니다.

주의사항

현재 파일에는 ‘실제 활동명’ 전용 입력칸이 없습니다. 학교에서 실제 운영한 활동명이 중요하면 교사 자유 기술이나 학생별 추가 기술에 직접 적어 주세요.

2학기 시기·행사 키워드

자율·자치에는 2학기 시작·개학, 겨울방학 준비, 학년 마무리, 학급·전교 임원 선거 관련 키워드를 추가했습니다. 실제로 실시한 행사만 선택하세요. 개학식·방학식·종업식·선거처럼 시기가 다른 활동은 한 문장에 억지로 섞지 않도록 구성했습니다.

문장 수는 기록할 근거의 수와 서로 다른 내용의 성격을 보고 정하는 것이 좋습니다.

기능 설명

학생당 평어 문장 수는 1~9문장으로 설정할 수 있으며, AI 결과는 설정한 문장 수와 명사형 종결 표현을 검사합니다.

활용 요령

한 가지 핵심 수행만 기록할 때는 1문장, 서로 다른 수행·참여 모습을 나누어 기록할 때는 2~3문장이 읽기 쉽습니다. 키워드가 많다고 문장 수를 무조건 늘릴 필요는 없습니다.

실제 예시

예: ‘내용을 이해함’과 ‘친구와 협력해 설명함’이 서로 다른 관찰 근거라면 한 문장에 억지로 합치기보다 2문장으로 나누는 편이 자연스럽습니다.

주의사항

모든 선택 키워드를 결과에 넣는 것이 목표가 아닙니다. 서로 성격이 다른 내용을 한 문장에 몰아넣으면 평어가 길고 부자연스러워질 수 있습니다.

AI 생성 전 실제 관찰 기록을 충분히 넣고, 생성 후에는 교사가 사실 여부와 표현을 반드시 검토합니다.

기능 설명

‘AI 평어 만들기’는 선택 키워드, 교사 자유 기술, 일괄 모드의 학생별 추가 기술, 문장 수와 문장 표현 설정을 바탕으로 Gemini에 초안을 요청합니다.

활용 요령

교사가 직접 입력한 실제 관찰·평가 기록을 가장 중요한 근거로 두세요. 참고 문서는 최대 10개까지 추가할 수 있고 각 문서에 ‘우선 참고할 내용’을 적을 수 있습니다. AI가 선택 키워드만 보고 학교에서 하지 않은 행사명, 대회명, 수상·성과를 만들어 내지 않았는지 반드시 확인하세요.

실제 예시

예: 동아리활동에서 ‘블록코딩’을 선택했다면 “친구와 순서를 정해 간단한 동작을 만들고 오류를 함께 고침”처럼 실제로 관찰한 장면을 추가 기록으로 적습니다.

주의사항

AI 결과는 최종 기록이 아니라 초안입니다. 수행하지 않은 활동, 확인되지 않은 성취, 근거 없는 마음·의도·성격 추정이 들어가지 않았는지 반드시 교사가 확인·수정하세요. 현재 HTML은 첨부 파일의 실제 본문을 Gemini 요청에 보내지 않고 파일명과 문서별 참고 지침을 생성 지침에 반영합니다.

문장 다양화 기능

같은 키워드를 여러 학생에게 사용해도 가능한 한 같은 문장을 그대로 반복하지 않도록 생성 과정에서 표현과 문장 구조를 달리하도록 구성되어 있습니다. 그래도 학생별 실제 관찰 근거가 다르면 학생별 추가 기술에 그 차이를 적어 주는 것이 가장 효과적입니다.

자연스러운 문장 다양화

비슷한 의미가 나오는 것은 허용하되 완전히 같은 문장을 되풀이하지 않도록 학생별로 활동 맥락의 제시 순서와 관찰 초점을 조금씩 달리합니다. 문장을 다르게 만들기 위해 없는 행동이나 과한 수식어를 추가하지 않으며, 자연스러움과 의미 일치를 가장 우선합니다.

내 평어함은 생성 결과를 최종 기록용으로 확인·수정·저장하는 작업 공간입니다.

기능 설명

생성 결과에서 ‘기존 평어함 지우고 붙이기’ 또는 ‘평어함 뒤에 이어붙이기’로 학생별 결과를 내 평어함에 저장할 수 있습니다. 일괄 저장도 지원합니다.

활용 요령

내 평어함에서 문장을 직접 수정한 뒤 ‘수정 저장’ 또는 ‘전체 수정 저장’으로 확정하세요. 전체 AI 재생성, 문장별 AI 재생성, 글자 수·문장 수 줄이기, 삭제 기능도 사용할 수 있습니다.

실제 예시

생성 결과를 먼저 이어붙인 뒤 내 평어함에서 실제 관찰과 맞지 않는 표현을 고치고, ‘같은 문장 검사·다르게 만들기’로 완전히 같은 문장만 확인할 수 있습니다.

주의사항

저장 전 수정이 있으면 저장 버튼이 빨간색으로 표시됩니다. Excel 복원은 평어 본문 중심이며 생성 근거·키워드 메타데이터는 복원하지 않습니다. 작업 상태까지 보존하려면 JSON 백업이 더 적합합니다.
