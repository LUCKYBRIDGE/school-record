5학년 2학기 교과 평어 활용 팁

학생 선택부터 내 평어함까지 단계별 사용법과 실제 활용 요령을 확인할 수 있습니다.

같은 키워드라도 문장이 똑같이 반복되지 않도록 구성했습니다.

동일한 키워드와 수준을 선택하더라도 학생별 평어가 가능한 한 서로 다른 문장으로 생성되도록 문장 구조·서술 순서·표현을 다양화하는 방식을 적용했습니다. 다만 AI 생성 결과가 항상 완벽하다고 보장할 수는 없으므로, 최종 사용 전에는 모든 문장을 한 번씩 읽어 사실관계·표현·중복 여부에 문제가 없는지 확인해 주세요.

학생 선택

5학년 교과 수행은 같은 기준으로 보더라도 학생마다 드러난 설명·적용·문제 해결 과정이 다를 수 있습니다.

기능 설명

한 학생 모드는 한 명씩 선택합니다. 여러 학생 일괄 모드에서는 여러 번호를 동시에 선택할 수 있으며, 2명 이상 선택하면 ‘학생별 추가 기술’을 펼쳐 개별 기록을 입력할 수 있습니다.

활용 요령

같은 단원·키워드를 여러 학생에게 적용할 때 공통적인 수업·평가 맥락은 교사 자유 기술에, 학생마다 다른 수행은 학생별 추가 기술에 나누어 적으면 결과가 덜 획일적입니다.

실제 예시

예: 여러 학생에게 수학 ‘분수의 곱셈’ 관련 기준을 함께 선택하되, 한 학생은 풀이 과정을 설명한 모습, 다른 학생은 계산 과정을 스스로 점검한 모습을 학생별 기록으로 구분합니다.

주의사항

일괄 생성에서도 실제 관찰이 다른 학생에게 똑같은 수행 근거를 복사하지 마세요. 번호만 다르고 근거가 같으면 결과도 비슷해질 수 있습니다.

키워드 선택

교과 키워드는 단원별 학습 수행을 고르고, 필요한 경우 하위 근거까지 좁혀 기록하는 구조입니다.

기능 설명

상위 키워드를 선택하면 관련 하위 키워드가 펼쳐집니다. 하위 키워드는 지식·이해, 과정·기능, 가치·태도로 구분됩니다. 좌클릭은 매우 잘함 → 잘함 → 보통 → 못함 → 매우 못함 → 해제 순입니다.

활용 요령

상위 키워드로 큰 수행을 잡고, 실제로 확인한 세부 근거가 있을 때만 하위 키워드를 1~2개 보완하는 방식이 좋습니다. 우클릭하면 즉시 해제되며, 상위 키워드 우클릭은 연결된 하위 선택도 함께 지웁니다.

실제 예시

예: 수학 ‘분수의 곱셈’ 단원에서 실제로 확인한 계산·설명 수행을 상위 키워드로 선택하고, 펼쳐지는 하위 항목 중 관찰 근거가 있는 지식·이해 또는 과정·기능만 추가합니다.

주의사항

성취기준과 단원 정보는 배경 자료입니다. 선택했다고 해서 학생이 실제로 수행한 증거가 되는 것은 아닙니다. 서로 다른 수준을 억지로 평균내거나 낮은 수준을 과장된 부정 표현으로 바꾸지 마세요.

문장 수

문장 수는 선택한 키워드의 양보다 ‘서로 다른 의미의 수행이 몇 가지인지’를 기준으로 정하는 편이 자연스럽습니다.

기능 설명

학생당 1~5문장을 설정할 수 있습니다. 1문장은 핵심 수행 하나를 간결하게 기록할 때, 2~3문장은 개념 이해와 과정·기능처럼 성격이 다른 근거를 나눌 때 적합합니다.

활용 요령

키워드가 많아도 모든 항목을 한 문장에 넣지 마세요. 핵심 근거만 남기고, 내용이 다르면 문장을 나누는 것이 읽기 쉽습니다.

실제 예시

예: 국어에서 작품에 대한 의견을 말한 근거와 서평을 작성한 근거가 모두 있다면 한 문장에 나열하기보다 의견 설명과 쓰기 수행으로 나누어 2문장으로 정리할 수 있습니다.

주의사항

문장 수를 늘린다고 새로운 성취가 생기는 것은 아닙니다. 근거가 하나뿐이면 1문장으로 충분하며, AI가 빈 내용을 보충해 새 수행을 만들지 않았는지 확인하세요.

AI 평어 생성

5학년 교과 평어는 개념 이해뿐 아니라 설명·추론·적용·문제 해결 과정이 실제 수업에서 어떻게 드러났는지를 근거로 확인하는 것이 중요합니다.

문장 다양화 기능

같은 키워드를 여러 학생에게 사용해도 가능한 한 같은 문장을 그대로 반복하지 않도록 생성 과정에서 표현과 문장 구조를 달리하도록 구성되어 있습니다. 그래도 학생별 실제 관찰 근거가 다르면 학생별 추가 기술에 그 차이를 적어 주는 것이 가장 효과적입니다.

기능 설명

교사 자유 기술, 일괄 모드의 학생별 추가 기술, 단원별 실제 활동명, 선택 키워드와 수준, 참고 문서의 파일명·문서별 참고 지침을 생성 지침에 반영해 Gemini API로 초안을 만듭니다.

활용 요령

‘풀이 과정을 친구에게 설명함’, ‘자료를 비교해 근거를 들어 의견을 말함’처럼 직접 관찰한 수행을 짧게 적는 것이 가장 효과적입니다. 단원별 ‘실제 활동명 추가’도 실제 수업 맥락을 구체화할 때 사용하세요.

실제 예시

예: ‘분수의 곱셈 문제를 해결한 뒤 계산 과정을 말로 설명하고 스스로 오류를 찾아 고침’처럼 확인한 장면을 자유 기술에 적고 관련 키워드를 선택해 초안을 생성합니다.

주의사항

교사가 입력한 관찰·평가 기록이 가장 중요한 근거이며 AI 결과는 초안입니다. 현재 직접 API 호출은 첨부 파일의 본문을 자동 전송하지 않고 파일명과 문서별 참고 지침을 텍스트 지침에 반영합니다. 문서 핵심 내용은 참고 지침이나 자유 기술에 직접 적고, 수행하지 않은 활동·확인되지 않은 성취·학생의 마음이나 의도를 AI가 만들어 내지 않았는지 반드시 검토하세요.

내 평어함

생성 결과를 바로 최종 기록으로 쓰기보다 내 평어함으로 옮긴 뒤 학생별 문장을 검토·수정하는 단계가 필요합니다.

마지막으로 한 번 읽어보기

자동 문장 다양화와 중복 확인 기능이 적용되어 있어도 최종 판단은 교사의 몫입니다. 내 평어함으로 옮긴 뒤 학생별 문장을 한 번씩 읽어 실제 관찰 내용과 맞는지, 지나치게 비슷한 문장이나 어색한 표현은 없는지 확인한 후 사용해 주세요.

내 평어함 이동 확인

평어를 옮기면 저장 완료 팝업에서 실제로 저장된 최종 내용을 바로 확인할 수 있습니다. ‘기존 평어함 지우고 붙이기’는 기존 내용이 있을 경우 먼저 기존 평어와 새 평어를 함께 보여 주며, 교체 여부를 확인한 뒤 실행됩니다.

기능 설명

생성 결과는 학생별로 기존 평어함 지우고 붙이기 또는 평어함 뒤에 이어붙이기가 가능합니다. 내 평어함에서는 직접 수정, 전체 평어 AI 재작성, 문장별 AI 재생성, 글자 수·문장 수 줄이기 기능을 사용할 수 있습니다.

활용 요령

초안을 옮긴 뒤 학생별 문장을 읽고 필요한 부분을 직접 고친 다음 수정 저장/전체 수정 저장으로 확정하세요. 마지막에 Excel로 내보내고, 작업 전체 보관이 필요하면 JSON 백업을 함께 사용하면 좋습니다.

실제 예시

예: 생성 결과를 ‘평어함 뒤에 이어붙이기’로 추가 → 표현 중복을 직접 수정 → 저장 전 변경 표시 확인 → 전체 수정 저장 → 교과 전체 Excel 저장 순으로 정리할 수 있습니다.

주의사항

‘같은 문장 검사·다르게 만들기’는 완전히 같은 문장만 대상으로 하며 의미가 비슷한 문장을 모두 판별하는 기능은 아닙니다. JSON은 설정·생성 결과·평어함 등을 폭넓게 복원하고, Excel 복원은 평어 본문 중심입니다.

자동 다양화와 중복 확인을 활용하되, 최종 사용 전 학생별 문장을 한 번 확인해 주세요.
