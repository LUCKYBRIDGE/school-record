버전 1 → 버전 2 주요 업데이트
  • 내 평어함 이동 완료 확인
    생성한 평어를 내 평어함에 붙인 뒤, 실제 반영 여부를 팝업 알림으로 바로 확인할 수 있도록 개선했습니다.
  • 기존 평어 덮어쓰기 보호
    이미 저장된 평어가 있는 학생에게 ‘지우고 붙이기’를 실행할 경우 기존 내용을 확인한 뒤 덮어쓸지 결정할 수 있도록 보호 기능을 강화했습니다.
  • 붙이기 동작을 더 명확하게 안내
    ‘기존 평어함 지우고 붙이기’와 ‘평어함 뒤에 이어붙이기’가 AI 생성 결과를 내 평어함으로 옮기는 기능이라는 점을 분명히 안내합니다.
  • 버전 1도 계속 이용 가능
    메인 화면의 ‘버전 1 · 이전’ 탭에서 기존 Gemini 공유 링크를 열거나 HTML을 다운로드·복사할 수 있습니다.
