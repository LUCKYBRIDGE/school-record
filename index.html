2. 사진으로 따라 하는 Gemini Canvas 매뉴얼

아래 실제 화면을 참고하여 1단계부터 8단계까지 순서대로 진행하세요.

Gemini 별도 창에서 시작하기

별도 브라우저 창으로 열기를 요청합니다. 브라우저 설정에 따라 새 탭으로 열릴 수 있습니다.

01Gemini에서 Canvas 선택

입력창 왼쪽 ＋를 누르고 Canvas를 선택하세요.

02Canvas 작업 창 열기

Canvas를 켠 뒤 안내 문장을 보내 작업 창을 엽니다.

입력 문장: 캔버스에 코드를 붙여넣어서 미리보기를 볼 거야. 캔버스 창 열어줘.

03Canvas 화면 확인

Canvas 작업 창이 열리는지 확인하세요.

04‘코드’ 탭 선택

상단의 코드 탭을 선택합니다.

05기존 코드 삭제 및 붙여넣기

편집창의 기존 코드를 전체 선택한 뒤 복사한 코드를 붙여넣습니다.

06코드 전체 확인

누락 없이 코드가 끝까지 들어갔는지 확인합니다.

07‘미리보기’ 누르기

미리보기에서 평어 생성기를 실행합니다.

08전체 화면으로 보기

원하면 오른쪽 위 전체 화면 아이콘을 누릅니다.
