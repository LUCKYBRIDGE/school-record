Gemini Canvas에서 실행하는 방법

코드 복사부터 미리보기까지 다음 순서로 진행하세요.

1

사용할 코드 복사

위에서 원하는 평어 항목의 전체 코드 복사 버튼을 누릅니다. 복사 완료 표시를 확인하세요.

2

Gemini에서 Canvas 선택

아래 Gemini 새 창 열기 버튼으로 본인의 Gemini에 접속한 다음 입력창의 ＋ 메뉴에서 Canvas를 선택합니다.

3

Canvas 작업 창 열기

Canvas가 선택된 상태에서 아래 문장을 입력하고 전송하면 코드 작업 창을 여는 데 도움이 됩니다.

캔버스에 코드를 붙여넣어서 미리보기를 볼 거야. 캔버스 창을 열어줘.
4

‘코드’ 탭으로 전환

Canvas 창 상단의 코드 탭을 누릅니다. 기존 코드가 있다면 편집 영역에서 전체 선택(Ctrl+A 또는 ⌘+A) 후 지웁니다.

5

코드 전체 붙여넣기

코드 편집 영역에 클릭한 다음 Ctrl+V(Windows) 또는 ⌘+V(Mac)로 복사한 코드를 그대로 붙여넣습니다. 우클릭 후 ‘붙여넣기’도 가능합니다.

6

미리보기에서 실행

붙여넣기가 끝나면 상단의 미리보기 탭을 클릭합니다. 평어 생성 화면이 보이면 사용할 수 있습니다. 더 넓게 보려면 전체 화면 버튼을 누르세요.

사용 전 확인 — 코드를 일부만 복사하거나 기존 코드 뒤에 덧붙이지 마세요. Gemini 화면 구성은 업데이트에 따라 달라질 수 있으며, 이 페이지에서는 Google 계정 정보나 학생 개인정보를 요구하지 않습니다.
