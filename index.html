2. 사진으로 따라 하는 Gemini Canvas 실행법

Gemini에 로그인한 다음, 아래 8단계를 순서대로 진행하세요. 실제 화면 예시를 함께 제공합니다.

Gemini를 별도 창에서 열기

버튼을 누르면 새 브라우저 창을 요청합니다. 브라우저 설정에 따라 새 탭이 열릴 수 있습니다.

01

Canvas 선택

Gemini 입력창 왼쪽 ＋를 누르고 Canvas 메뉴를 선택하세요.

02

Canvas 열기 요청

아래 안내 문장을 입력한 후 전송해 Canvas 작업 화면을 엽니다.

캔버스에 코드를 붙여넣어서 미리보기를 볼 거야. 캔버스 창 열어줘.
03

Canvas 창 확인

Gemini가 만든 Canvas 작업 창이 나타나는지 확인하세요. 처음에는 미리보기 상태일 수 있습니다.

04

‘코드’ 탭 선택

Canvas 상단의 코드 탭을 눌러 코드 편집 화면으로 이동하세요.

05

기존 코드 지우고 붙여넣기

편집기 클릭 → Ctrl+A / ⌘+A로 기존 코드 전체 선택 → 새 코드 Ctrl+V / ⌘+V 붙여넣기.

06

코드 전체 확인

복사한 코드가 끝까지 들어갔는지 확인하세요. 코드를 이어 붙이지 말고 전체 교체해야 합니다.

07

‘미리보기’로 실행

미리보기 탭을 눌러 실제 평어 생성기가 표시되는지 확인합니다.

08

전체 화면으로 보기

더 넓게 사용하고 싶다면 Canvas 상단의 전체 화면 아이콘을 선택하세요.
