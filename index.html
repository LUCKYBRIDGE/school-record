놀평어 VERSION 4 업데이트

저장 후 바로 이어지는 다음 학생 작성 흐름을 개선했습니다.

현재 1~6학년 2학기 교과·창체·행발의 기본 실행 버전은 버전 4입니다. 교과전담은 기존 최신 버전 3을 유지합니다.

버전 4 주요 업데이트
  • 다음 학생 준비/작성 흐름 추가
    평어 저장을 마친 뒤 현재 작업용 키워드와 방금 생성한 결과를 정리하고 학생 선택 영역으로 바로 이동할 수 있습니다.
  • 저장 전에도 빠르게 다음 학생으로 이동
    필요할 때 키워드 선택을 한 번에 정리하고 학생 선택 영역으로 이동할 수 있어 반복 작성 동선을 줄였습니다.
  • 교과·창체·행발 공통 적용
    1~6학년 세 영역 모두 같은 작업 흐름을 사용할 수 있도록 정리했습니다.
  • 기존 저장 보호 기능 유지
    내 평어함 저장 확인, 기존 내용 교체/이어붙이기 구분, 저장 결과 확인 등 기존 안전 기능은 유지됩니다.
권장 설정 · 생성 성능이 가장 안정적입니다

선택한 키워드 수와 생성할 문장 수를 같게 맞춰 주세요. 예: 키워드 3개 → 3문장.

버전 1~4 업데이트 내용 요약 보기
VERSION 1

기본 평어 생성기 구축

1~6학년 교과·창체·행발 생성기를 제공하고, Gemini 공유 링크와 HTML 다운로드·코드 복사 방식의 기본 구조를 마련했습니다.

VERSION 2

내 평어함 저장 안전성 강화

기존 평어 교체와 뒤에 이어붙이기를 구분하고, 저장 완료 내용과 기존 내용 덮어쓰기 여부를 확인할 수 있도록 저장 보호 흐름을 강화했습니다.

VERSION 3 계열

선택·결과 확인·평어 내용 개선

학생 전체선택/해제와 결과 넓게 보기를 개선하고 창체·행발 내용을 보강했습니다. v3.1에서는 행발의 성장 중심 서술, 완곡 표현과 말투 선택을 추가로 다듬었습니다.

VERSION 4 · 최신

다음 학생 작성 흐름 개선

저장 후 작업용 키워드와 방금 생성한 결과를 정리하고 학생 선택으로 바로 이동하는 기능을 1~6학년 교과·창체·행발에 공통 적용했습니다.

공유 링크가 열리지 않을 때 · 각 카드의 HTML 전체 복사를 누른 뒤 코드 복사 매뉴얼을 따라 Gemini Canvas에서 실행할 수 있습니다. 다운로드한 HTML은 백업·보관용으로도 사용할 수 있습니다.
