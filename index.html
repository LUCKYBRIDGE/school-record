코드 복사부터 실행까지

Gemini Canvas 공유 화면에서 정상 실행되지 않는 경우, 아래 순서에 따라 본인의 Gemini에서 코드를 직접 실행할 수 있습니다.

이 페이지는 Gemini의 공식 서비스가 아닌 별도 사용 안내 페이지입니다. Google 계정 로그인은 Gemini 공식 사이트에서만 진행하세요.
1

전체 코드 복사

아래 버튼을 누르면 실행에 필요한 코드 전체가 복사됩니다. 코드 일부만 선택할 필요가 없습니다.

코드가 아직 등록되지 않았습니다. 등록 후 복사 버튼이 활성화됩니다.
복사할 코드 미리 보기
아직 등록된 코드가 없습니다.
2

Gemini를 새 창으로 열기

본인의 Google 계정으로 로그인하세요. 아래 버튼은 가능한 경우 별도 브라우저 창을 요청합니다.

직접 열기 ↗
3

Canvas에 코드 붙여넣기

  1. Gemini에서 Canvas 기능을 열고 코드 편집 화면으로 이동합니다.
  2. 기존 코드가 있으면 전체 선택 후 지웁니다.
  3. 1단계에서 복사한 코드를 그대로 붙여넣습니다. (Windows: Ctrl+V / Mac: ⌘+V)

Gemini의 실제 메뉴 명칭과 화면 구성은 계정 또는 서비스 업데이트에 따라 달라질 수 있습니다.

4

미리보기에서 실행

Canvas의 미리보기 화면에서 실행 상태를 확인하세요. 코드가 실행되지 않는 경우 전체 코드가 빠짐없이 붙여넣어졌는지 먼저 확인합니다.

코드 공유용 안내 페이지 · 개인정보나 Google 비밀번호를 이 페이지에 입력하지 마세요.
