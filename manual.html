공유 링크가 안 열리나요?
HTML 코드로 직접 실행하세요.

Gemini 공유 링크가 열리지 않거나 실행이 어려울 때 사용하는 보조 방법입니다. 해당 학년·영역의 HTML 전체 코드를 복사한 뒤 사진 매뉴얼을 따라 본인의 Gemini Canvas에 붙여넣으세요.

① 평어 코드 선택② 사진 매뉴얼 보기

1. 평어 코드 선택

학년을 선택한 뒤 교과·창체·행발 중 필요한 HTML 전체 코드를 복사하세요.

현재 제공 자료 · 1~6학년 교과·창체·행발은 v4 최신 · 교과전담은 v3 최신
v4 주요 개선 · 최대 9문장 지원 · 다음 학생 작성 흐름 · 행발의 자연스러운 보완·성장 기대 표현
권장 설정 · 선택한 키워드 수와 생성할 문장 수를 같게 맞추면 가장 안정적인 생성 성능을 얻을 수 있습니다.

2. 사진으로 따라 하는 Gemini Canvas 실행법

HTML 전체 복사가 끝났다면 아래 순서대로 진행하세요. 실제 Gemini 화면을 기준으로 안내합니다.

Gemini를 별도 창에서 열기

버튼을 누르면 별도의 브라우저 창으로 열기를 요청합니다. 브라우저 설정에 따라 새 탭으로 열릴 수 있습니다.

01

Canvas 선택

Gemini 입력창 왼쪽 ＋를 누르고 Canvas를 선택하세요.

02

Canvas 열기 요청

Canvas가 선택된 상태에서 아래 문장을 보내 작업 화면을 엽니다.

캔버스에 코드를 붙여넣어서 미리보기를 볼 거야. 캔버스 창 열어줘.
03

Canvas 창 확인

Canvas 작업 창이 오른쪽에 열리는지 확인하세요.

04

‘코드’ 탭 선택

상단의 코드 탭을 눌러 코드 편집 영역으로 이동합니다.

05

기존 코드 삭제 후 붙여넣기

코드 편집 영역을 클릭하고 Ctrl+A / ⌘+A로 기존 코드를 모두 선택해 지운 뒤, Ctrl+V / ⌘+V로 복사한 HTML 전체를 붙여넣습니다.

06

코드 전체 확인

붙여넣기가 끝날 때까지 기다린 뒤 코드가 편집 영역에 들어갔는지 확인합니다.

07

‘미리보기’로 실행

미리보기 탭을 누르면 복사한 놀평어 생성기가 실행됩니다.

08

전체 화면으로 보기

더 넓게 사용하려면 Canvas 오른쪽 위의 전체 화면 아이콘을 누르세요.
